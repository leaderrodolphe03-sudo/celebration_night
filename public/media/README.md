# Médias officiels

Fichiers fournis par l'organisation de CELEBRATION NIGHT. Pour remplacer un visuel,
déposer le nouveau fichier sous le **même nom** (ou modifier son chemin dans
`lib/content.ts`, section `MEDIA`). À terme, ces emplacements seront gérés depuis
l'administration (Supabase Storage).

| Fichier | Emplacement |
|---|---|
| `official/logo-celebration-night.webp` | Logo principal (fond transparent) |
| `official/affiche-2025-chantres-invites.jpg` | Archives 2025, galerie |
| `official/affiche-2025-groupe-hote.jpg` | Archives 2025, galerie |
| `official/banniere-2025-coming-soon.jpg` | Galerie |

Les images de `public/images/` sont des illustrations générées, sans lien avec
l'événement : elles ne sont plus utilisées par le site public.
